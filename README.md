
# Restaurant Ordering App

This project from Scrimba's course, The Frontend Developer Career Path, is a simple web-based application designed to simulate a restaurant ordering system. It allows users to browse a menu, select items, and view their order in real time. The project is structured as a collaborative learning experience.


## Features


- Menu Display: A list of available food items with descriptions and prices.
- Order Selection: Users can select items from the menu and build their order.
- Real-Time Order Updates: The app updates the total cost as users add or remove items.



## Technologies Used

- HTML: Structuring the web content.
- CSS: Styling the interface for a pleasant user experience.
- JavaScript: Adding interactivity, such as dynamically updating the order and prices.



## Getting Started

1. **Clone the repository:**

```
git clone https://github.com/karen-pcsta/restaurant-ordering-app.git

```

2. **Navigate to the project directory:**

```
cd restaurant-ordering-app
```

3. **Open the index.html file in your browser to see the application in action.**
